# stephanwebsitefrontend

Frontend landing page for Social Studying AI.

Open `index.html` in a browser or serve the directory with any static web server.

## Deployment

GitHub Actions deploys `main` to the Azure Static Web App and creates preview
environments for pull requests. Add the Static Web App deployment token to the
GitHub repository as an Actions secret named `AZURE_STATIC_WEB_APPS_API_TOKEN`.

The workflow can also be run manually from **Actions > Deploy Azure Static Web
App > Run workflow**.
